  1. ScriptStructured narration text: the single source of truth for words, timing cues and captions
  2. Physics checksPython recomputes every number on screen; the build stops if one fails
  3. NarrationNeural text-to-speech run locally, with word-level timing
  4. AnimationRemotion (React + TypeScript), keyed to the spoken words
  5. Mix & encodeFFmpeg: EBU R128 loudness, 1080p H.264
  6. QA gateAutomated checks on the finished file before anything is published

Numbers are computed, not typed

A script recomputes each quantitative claim, for example that a 1 nm mirror move shifts the interferometer phase by 4π·1/633 rad ≈ 1.14°. {{ s.physics_checks }} such checks run in episodes 2 and 3; episode 1's claims are traced to a written source list.

The picture follows the voice

Animations are keyed to the narration's word timings, so a diagram changes on the word that names it. Caption timing is measured against the actual speech onsets: the worst case is {{ s.sync_worst_ms }} ms, against a limit of {{ s.sync_limit_ms }} ms.

Every build is versioned and gated

Builds are never overwritten. Format, duration, loudness (−16 LUFS, no clipping), black or frozen frames, and a speech-recognition comparison of audio and captions must all pass before a build can be published.
